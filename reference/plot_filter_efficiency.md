# Efficiency scatter plot with labeled/unlabeled/retained categories

Efficiency scatter plot with labeled/unlabeled/retained categories

## Usage

``` r
plot_filter_efficiency(
  qsip_data_object,
  ncol = NULL,
  nrow = NULL,
  use_counts = FALSE
)
```

## Arguments

- qsip_data_object:

  A filtered qsip_data object (or list)

- add_diagonal:

  Add reference diagonal line

## Value

A ggplot2 object
